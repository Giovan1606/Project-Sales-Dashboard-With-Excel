# Retail Sales Dashboard

## Project Overview

A retail sales analysis project focused on understanding sales performance, customer characteristics, product profitability, and product returns using Microsoft Excel.

## Data Cleaning

The dataset was cleaned and prepared using Power Query by standardizing inconsistent values, removing unnecessary spaces, and transforming date information for further analysis.

## Data Analysis

The project includes:

- Power Pivot Data Model
- Relationships between tables
- DAX Measures
- Calculated Fields
- What-If Analysis
- Pivot Tables and Pivot Charts

## Key Analysis

The analysis covers:

- Sales by Product Category
- Sales Trends by Year
- Returned vs Not Returned
- Monthly Sales and Return Trends
- Profit by Product Category
- Average Customer Age

## Interactive Dashboard

An interactive dashboard was developed to provide an overview of sales performance, profit, customer characteristics, and product returns.

The dashboard includes:

- Average Age
- Total Quantity Sold
- Total Returned
- Sales by Category
- Sales Trend
- Return Analysis
- Profit by Product Category

## Tools

- Microsoft Excel
- Power Query
- Power Pivot
- DAX
- Pivot Table
- Pivot Chart
